# DHS Program acknowledgements

The following surveys were used or assessed for this analysis. Each is distributed by The DHS Program (ICF, funded primarily by USAID). Investigators must register at https://www.dhsprogram.com/data/ and obtain country-specific approval. Datasets must not be passed to other researchers without written consent of The DHS Program. Publications using the data should be sent to The DHS Program Data Archive.
